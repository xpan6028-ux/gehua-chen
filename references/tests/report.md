# 验证记录：用途、路径与条件修正

日期：2026-10-25。验收重点是普通组合任务能正确触发、讲解/计划/运行条件不互套，以及不依赖启动目录。以下为当前版本记录；第一版未执行Stata的情景回答仅作为历史档案保留，不是当前执行规范。

## 已修正的问题

- SKILL用途由“整理视频知识”改为控制变量组合回归与结果敏感性比较，描述覆盖自然语言的排列组合/批量回归请求；原版OneClick为可选分支。
- 从当前宿主提供的SKILL绝对位置解析资源，不默认Codex私有目录；命令展开为绝对Python/脚本/配置/输出路径。新增自身定位的Windows演示入口，不再依赖未定义的Python变量。
- 讲解不需要环境；plan仅需Python，允许未取得DTA或尚未指定数据；原版plan不要求ado目录。run才检查数据、Stata及原版源码条件。计划未给数据时不会偷换为auto。
- 相对data_path、output-root、ado-dir统一相对配置目录，避免cwd变化；生成的do先cd到绝对运行目录，启动Stata也传do绝对路径。STATA_EXE可给PATH上的命令名。
- 原版与扩展的候选数量、输出列冲突、指数存储开销和推断条件分别说明；用户已授权运行时不重复确认；无法执行时交付计划/代码并明确缺项。
- 示例Stata输出用tempfile绝对临时路径；历史试答标注为档案，避免其中旧环境状态与旧命令被误当成当前指令。

路径测试实际做了：从两个无关cwd执行同一绝对入口；将技能复制到带中文/空格的其他工具目录后执行；确认输出没有落入调用cwd；检查do指向迁移后collector及绝对运行目录；在未找到Stata和ado的情况下生成原版计划；在DTA尚未取得或数据字段未填写时生成计划，并确认run会拒绝；验证演示ps1从另一个cwd产生4条计划。首轮ps1测试发现中文Python路径的编码识别失败，给探测解释器加UTF-8模式后9项全部通过。

实际Stata测试覆盖：auto四规格的b/SE/N/p与独立手写回归及lincom按double精度一致；全部不显著仍保留；两成功/两失败不串e()；目标省略不造p；共同输入池和逐规格样本差异；Logit/Probit保留缺失普通R²与单列伪R²；xtreg FE/reghdfe聚类自由度；四聚类时原生t推断；原版产生筛选结果及无匹配报错；空样本、无完成标记、超时和变量缩写拒绝。Stata返回version18、flavor IC，不依据程序名推断MP许可。

## 独立前向使用

未继承创建过程的评估代理只收到技能目录和“y/x与a/b/c，数据下周才给，今天只要计划”的用户请求。它读取主文件与必要资料，在独立目录实际生成8条组合计划、CSV和结构化JSON，每组保留x；未确定模型、标准误和样本策略标待定。没有因数据/环境未就绪而阻塞，没有查找、安装或运行Stata，没有修改仓库。该场景未发现指令矛盾，产物留在本机测试目录。

## 覆盖边界

跨目录与迁移安装测试证明文件定位逻辑可用，不代表已在豆包、Claude等每个宿主完成原生导入/进程权限验收。实际运行仍依赖宿主能力和软件环境。xtreg RE、其他操作系统、任意估计器/复杂交互/权重接口、真实用户研究数据与提速百分比未作本轮验收。未取得完整视频转录。JSON接口未支持的模型不应被删减设定强行套用；相应独立do需另行验证。
