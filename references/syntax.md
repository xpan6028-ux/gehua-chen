# OneClick 6.0：语法与参数

依据本次取得的官方6.0源码及2024-11-23帮助文件。日期与来源见 [sources.md](sources.md)。下面是对接口的解释，不是视频逐字稿；执行前用本机 `which oneclick` 和 `viewsource oneclick.ado` 对版本。

## 基本语法与变量角色

```stata
oneclick y c1 c2 ..., method(estimator) pvalue(alpha) fixvar(x fixed_controls ...) ///
    [options(estimator_options) zvalue threshold(k) saveplace(filename) best full]
```

| 位置 | 含义 | 不能混淆的地方 |
| --- | --- | --- |
| 逗号前第一个变量y | 被解释变量 | 不在此位置放一整条现成回归命令 |
| 逗号前其余变量c1 c2 ... | 被枚举的候选控制变量 | 6.0 `min=3` 指整个varlist最少3项，即y加至少2个候选 |
| `fixvar()`第一项x | 每个规格保留且被检验的解释变量 | 不保证其中每个固定变量都显著 |
| `fixvar()`其余项 | 固定保留的控制变量或可用的虚拟变量项 | 不参加候选子集数量计算 |

`fixvar(x z1 z2)`表示始终保留x、z1和z2，但p值筛选只检查x。没有额外的预设正/负方向选项；方向在结果中分别标记。

## 参数详解

| 参数 | 作用 | 需要核查的条件 |
| --- | --- | --- |
| `method(regress)`等 | 指定每个组合使用的估计命令 | 需命令已安装、接受对应语法，且返回所需系数/标准误；不是自动兼容全部Stata命令 |
| `pvalue(.05)` | 指定筛选上限 | 业务上应使用0与1之间的合理阈值；源码筛选为严格`pv < pvalue`，不是小于等于 |
| `fixvar(x ...)` | 指定受检验变量和固定保留项 | 第一项必须能正确映射到被检验的单一系数 |
| `options(...)` | 把内容传给估计器逗号后的选项 | 例如`options(vce(robust))`或`options(absorb(id year) vce(cluster id))`；估计器必须支持这些选项 |
| `zvalue` | 用标准正态近似计算双侧p值 | 没有此选项时，源码尝试用`e(df_r)`计算t检验；自由度缺失且没加z可能失败 |
| `threshold(3)` | 每个保留规格至少3个候选控制变量 | 不把固定保留项计入3；候选仅2个时设3不会凭空增加变量 |
| `saveplace("run01.dta")` | 指定保存的结果文件名或路径 | 源码使用`replace`，运行前应选新文件名/隔离目录 |
| `full` | 将输出中的子集文字换成完整回归命令 | 仍然只输出通过筛选的组合；不代表全部结果、不添加N或精确p |
| `best` | 在筛选结果中按存下的R²挑一行并重跑 | R²缺失、样本变化、拟合度与识别目标的区别都影响解释，不默认启用 |

长参数名通常可按源码允许的缩写使用，如`m()`、`p()`、`fix()`、`o()`、`z`。首次讲解与可维护脚本优先写全名，避免把简写误认成另一个版本接口。

## t检验与z检验

源码先计算受检验系数与标准误之比，再使用：

- 未设置`zvalue`且`e(df_r)`非缺失：双侧t尾概率。
- 设置`zvalue`：双侧标准正态尾概率。

这只是该程序的实现，不能替代估计器自身的推断定义。OLS通常有剩余自由度；某些模型使用z统计量。`xtreg, fe`与默认随机效应不能简单混为一谈；需核对实际输出与`ereturn list`。多参数联合检验、工具变量相关诊断、特殊自助法p值等不能直接等同这个单系数比值。

## 固定效应与标准误

- 估计器为`regress`时，可在固定保留项中放适合的数据分类项，如`i.year`。
- `xtreg`需预先正确`xtset`；`fe`放入`options(fe ...)`，时间虚拟变量可按需要放进固定保留项。
- `reghdfe`的吸收项放进`options(absorb(id year) ...)`，不让每个固定效应虚拟变量参与候选控制变量的枚举。
- `vce(robust)`和`vce(cluster id)`是不同设定；由设计决定，不能为追求显著性任意切换。
- 核心变量为交互项、因子变量或时序项时，先做一条基准回归，核对实际系数名称。接口允许`fv ts`不等于所有表达式都能被`_b[x]`正确提取。

## 版本与依赖

当前核验的6.0使用内置的位图枚举，没有调用`tuples`。作者旧GitHub README中的`tuples`依赖说明不能直接沿用到6.0。指定估计器及其依赖仍须单独检查。

程序最低声明Stata14。包中保留旧程序`oneclick5`，但只分发`oneclick.ado`与帮助文件，未单独分发`oneclick5.ado`。新会话能否直接自动加载`oneclick5`需要核对，不把“旧功能存在”当作“任意会话直接调用一定成功”。

若用户实际安装的文件与本快照不同，以实际文件为准，登记版本差异后再生成代码。不能仅凭安装命令成功判断就是视频中的6.0版本。
