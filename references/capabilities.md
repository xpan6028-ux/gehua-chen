# 功能与条件

主用途是控制变量组合回归与结果敏感性比较；OneClick6.0资料是可选的命令讲解与原版入口依据，不是每次任务的必经步骤。

| 功能 | 可以交付 | 实际条件 |
| --- | --- | --- |
| 概念/命令讲解、解释已有表或日志 | 有依据的回答、候选原因、核查建议 | 不依赖Python、Stata或完整数据 |
| 组合计数、规划、代码生成 | 组合范围、基准模型拆解、JSON/do | 可以在数据未提供时完成规划；用plan脚本需Python3.9+，不需Stata/ado |
| fullspec实际执行 | 全部计划规格、数值p/SE/N、失败/省略状态、代码和日志 | 当前宿主可启动进程，DTA可读，Stata与所需估计器可用；不需OneClick |
| 原版oneclick实际执行 | 原算法筛选后的非空显著组合 | 以上条件加固定哈希的原版ado目录；全局安装不是本包装器源码条件的替代 |
| 比较与追问 | 比较系数、p和N，检查日志并说明仍待核实的解释 | 读取当前可获得的实际结果；不把缺失信息编成结论 |

fullspec允许0个候选（只估基准模型）或1个候选；默认枚举0至全部候选，预算256个。可以指定最少/最多候选数量。必须保留的变量、固定效应与标准误按用户基准模型处理；未说明哪些变量可变化时不自动把所有控制项列为候选。

执行器用脚本自身位置解析内部资源；AI调用则从当前宿主给出的SKILL绝对位置取得根目录，展开脚本、配置与输出绝对路径。跨目录/迁移位置的计划测试通过，不代表已在每种AI宿主原生安装并执行；外部宿主还需要实际文件与进程权限。脚本和结果不依赖Codex私有接口。

实际Stata验收覆盖Windows Stata18（c(flavor)=IC）、auto和固定种子合成数据、OLS、Logit/Probit、xtreg FE、reghdfe及稳健/聚类标准误。用户具体研究数据、xtreg RE和其他系统仍需针对性验证，不能从教学验收推断任意数据或模型均可估计。

JSON接口尚未覆盖任意估计器、权重、自由options、if/in或复杂交互/时序目标；此时可以按任务另写do或说明执行缺项，不以删除原设定来凑可运行输入。尚未自动生成规格曲线、逐观察样本成员对比或完整识别有效性审查。

common是共同完整案例输入池，实际估计样本仍可能不同；查看common_pool_complete等字段。估计失败、目标被省略、不显著与无法推断分别记录。组合结果为探索/敏感性材料，不保证显著、符号、提速百分比或因果结论。
